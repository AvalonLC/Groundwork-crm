What changed vs. today's My Day

  • One hero, not eight equals. Today's Jobs leads full-width; everything else is intentionally secondary. Only 4 widgets on screen by default instead of 8.
  • New stat strip gives one calm, confident glance (pipeline, jobs, tasks, money owed) before any widget detail — the "anchor" every premium dashboard has.
  • Pipeline is a real chart now — 4-week trend sparkline + a stage-by-stage (Prospecting/Quoted/Negotiating/Won) breakdown bar with a legend, not just a number and a plain progress bar.
  • One unified card (radius, border, shadow, header type) used everywhere — pulled from the GW-002 tokens already in the codebase, just applied consistently.
  • Fixed-height, evenly aligned row. Tasks / Calendar / Pipeline are always the same height as each other, whether today has 1 task or 12 — verified pixel-for-pixel with no clipped rows on either a light day or a busy day.
  • "+N more" instead of a scrollbar or an ever-growing card. Jobs/Tasks/Calendar each show a capped number of rows; anything past the cap collapses into a quiet link (e.g. "2 more tasks — view all") so the layout looks identical every day regardless of real data volume.
  • 4 mode pills → 1 segmented control, and Customize collapses to an icon button, so the header isn't a row of 6 competing buttons.
  • No drag-dots / arrows / width-cycle buttons visible unless you're actually in Customize mode — the view screen looks like content, not an admin panel.
